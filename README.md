# 🎮 ASCII Arcade Games (C# .NET)

## 📌 Overview

This project is a collection of **ASCII-style terminal games** built using **C# and .NET**.
The goal is to design and develop a **custom lightweight game engine** that runs entirely in the console and supports multiple mini-games.

Instead of using external game frameworks, everything is built from scratch to better understand:

* Game loops
* Rendering in console
* Input handling
* Basic game architecture

---

## 🚀 Features

* 🧩 Multiple playable ASCII games
* ⚙️ Custom-built game engine
* 🎮 Real-time keyboard input handling
* 💾 Save/Load system using SQLite
* 🖥️ Pure console-based rendering

---

## 🛠️ Tech Stack

* **Language:** C#
* **Framework:** .NET
* **Platform:** Console Application
* **Database:** SQLite (for game saves)
* **IDE:** Visual Studio

---

## ▶️ Getting Started

### Prerequisites

* .NET SDK installed
* Visual Studio (recommended)

### Run the Project

```bash
git clone https://github.com/TalhaAhmad-Codes/AsciiArcadeGames
cd AsciiArcadeGames/Game
dotnet run
```
